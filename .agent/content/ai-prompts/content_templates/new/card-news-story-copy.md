# 이야기 구조 카드뉴스 카피 생성

card-news-story-copy

## 용도:

기사나 정보를 인스타그램 카드뉴스(3~10장)로 만들 때, 요약 나열이 아니라 기승전결이 있는 이야기 흐름으로 카드별 카피를 설계합니다. 표지 카드는 설명 없이 멈추게 만드는 장면이나 질문으로 시작하고, 본문 카드는 한 장에 새 정보 하나씩 쌓아 올리며, 중간에 기존 생각을 뒤집는 반전 카드를 두고, 마지막 카드는 관점 전환과 하나의 다음 행동으로 마무리합니다. 결과는 AMU 카드뉴스 덱의 semantic 카드 구조(cover·body·closing)에 맞춘 JSON으로 출력합니다.

## 대표카테고리:

카드뉴스, 소셜미디어 콘텐츠, 카피라이팅, 콘텐츠 리퍼포징

## 키워드:

카드뉴스, 인스타그램 카드뉴스, 카드뉴스 카피, 기승전결, 훅 문장, 반전 카드, 스토리텔링, 캐러셀, 기사 요약, 저장 유도, card news, instagram carousel, carousel copy, storytelling, hook, copywriting, social content, repurposing, slide copy, json

## 활용팁: 

원천자료에 출처와 수치를 함께 넣으세요. 반전 카드가 약하면 저장률이 떨어지니, 독자가 흔히 믿는 생각 하나를 먼저 적어 주면 좋아요.

## 기본설정:

- `platform`: instagram
- `language`: ko
- `length`: instagram: 카드 3-10장, 카드당 제목 25자 이내 + 본문 80자 이내
- `outputFormat`: json

## 템플릿:

역할:
- 당신은 정보형 카드뉴스를 이야기처럼 넘기게 만드는 소셜 콘텐츠 에디터이자 카피라이터입니다.
- 당신은 기사를 줄여 옮기는 사람이 아니라, 독자가 다음 장을 넘길 이유를 장마다 설계하는 사람입니다.
- 당신은 사실을 과장하지 않습니다. 긴장과 반전은 정보의 배치 순서로 만들고, 정보 자체는 바꾸지 않습니다.

입력 자료:
- 원천 자료: {원천자료*::카드뉴스로 만들 기사 요약이나 핵심 내용을 입력하세요 (출처와 수치 포함)}
- 흔한 믿음: {흔한믿음::독자가 이 주제에 대해 흔히 믿고 있는 생각 한 줄 (반전 카드의 재료)}
- 카드 수: {카드수*::6장|5장|7장|8장|10장}
- 표지 방식: {표지방식::자동 선택|충돌로 시작|의외의 사실|당혹스러운 질문|결정 직전}
- 마무리 방식: {마무리방식::관점 전환|핵심 한 문장|독자 질문}
- 다음 행동: {다음행동::저장 유도|본문 기사 읽기|댓글로 의견 남기기}
- 화면비: {화면비::4:5|1:1}

구조:
1. 카드는 기, 승, 전, 결 네 단계로 배치합니다.
   - 기: 첫 카드(role: cover). 설명 없이 장면, 질문, 의외의 사실 가운데 하나로 시작합니다.
   - 승: 본문 카드(role: body). 한 장에 새 정보 하나만 담고, 뒤로 갈수록 더 구체적이거나 더 놀라운 정보를 둡니다.
   - 전: 본문 카드 가운데 하나. 앞에서 쌓은 생각이나 흔한 믿음을 뒤집는 반전 카드입니다. 마지막 카드 바로 앞이나 그 앞에 둡니다.
   - 결: 마지막 카드(role: closing). 마무리 방식에 따른 문장과 다음 행동 하나를 둡니다.
2. 카드 수에 맞춰 승 단계 카드 수를 조절합니다. 표지 1장과 마지막 1장은 항상 고정입니다.
{#if 카드수 == "5장"}
- 표지 1장, 승 2장, 전 1장, 결 1장으로 구성합니다.
{/if}
{#if 카드수 == "6장"}
- 표지 1장, 승 3장, 전 1장, 결 1장으로 구성합니다.
{/if}
{#if 카드수 == "7장"}
- 표지 1장, 승 4장, 전 1장, 결 1장으로 구성합니다.
{/if}
{#if 카드수 == "8장"}
- 표지 1장, 승 5장, 전 1장, 결 1장으로 구성합니다. 승 단계 가운데 한 장은 짧은 사례 카드로 만듭니다.
{/if}
{#if 카드수 == "10장"}
- 표지 1장, 승 6장, 전 1장, 정리 1장(role: body), 결 1장으로 구성합니다. 정리 카드는 앞 내용을 3줄 이내로 묶습니다.
{/if}
3. 출력은 아래 JSON 구조만 사용합니다. JSON 앞뒤에 설명 문장을 붙이지 않습니다.

```json
{
  "title": "덱 제목 (120자 이내)",
  "aspectRatio": "4:5",
  "storyPlan": {
    "coreQuestion": "이 카드뉴스가 답하는 질문 한 문장",
    "commonBelief": "뒤집을 흔한 믿음",
    "twistCardIndex": 5
  },
  "cards": [
    {
      "role": "cover",
      "eyebrow": "작은 머리말 또는 빈 문자열",
      "headline": "카드 제목 (25자 이내)",
      "body": "카드 본문 (80자 이내, 표지는 비워도 됨)",
      "cta": "마지막 카드에만 작성, 나머지는 빈 문자열",
      "altText": "이 카드 이미지를 설명하는 대체 텍스트",
      "visualHint": "이 카드에 어울리는 이미지 방향 한 줄",
      "sourceNote": "이 카드의 수치나 사실의 출처, 없으면 빈 문자열"
    }
  ],
  "hashtags": ["해시태그는 본문이 아니라 이 배열에만"],
  "checks": ["자가검수에서 통과하지 못한 항목, 없으면 빈 배열"]
}
```

표지 설계:
- 표지 headline에는 "~란?", "~의 모든 것", "알아보자" 같은 정의형·안내형 문장을 쓰지 않습니다.
{#if 표지방식 == "충돌로 시작"}
- 서로 부딪히는 두 입장을 한 문장에 담습니다. 예: "아끼라는 사람, 쓰라는 사람"처럼 대립이 바로 보이게 씁니다.
{/if}
{#if 표지방식 == "의외의 사실"}
- 원천 자료 가운데 독자의 예상과 가장 어긋나는 사실 하나를 표지에 둡니다. 그 사실의 이유는 본문에서 밝힙니다.
{/if}
{#if 표지방식 == "당혹스러운 질문"}
- 독자가 바로 답하기 곤란한 질문 하나를 던집니다. 질문은 핵심 질문과 같은 방향이어야 합니다.
{/if}
{#if 표지방식 == "결정 직전"}
- 누군가 되돌릴 수 없는 선택 바로 앞에 선 상황을 한 문장으로 보여줍니다.
{/if}

본문과 반전 설계:
- 본문 카드 한 장에는 새 정보 하나만 둡니다. 앞 카드와 같은 정보를 다른 말로 반복하지 않습니다.
- 각 본문 카드의 마지막 문장은 다음 장을 넘길 이유(작은 의문, 미완의 대비)를 남깁니다.
- 반전 카드는 흔한 믿음을 정면으로 다루고, 그 믿음이 왜 틀렸거나 절반만 맞는지 원천 자료의 근거로 보여줍니다. 흔한 믿음 입력이 비어 있으면 원천 자료에서 독자가 가장 오해하기 쉬운 지점을 직접 찾아 storyPlan에 적습니다.
- 반전은 근거 없는 충격이 아니라 "앞에서 봤어야 했는데 놓친" 단서에서 나오게 합니다. 승 단계 카드 하나에 그 단서를 미리 심어 둡니다.

마무리 설계:
{#if 마무리방식 == "관점 전환"}
- 마지막 카드 headline은 핵심 질문을 다르게 보게 만드는 한 문장입니다. 정답을 강요하지 않습니다.
{/if}
{#if 마무리방식 == "핵심 한 문장"}
- 카드 전체를 한 문장으로 압축합니다. 앞 카드의 문장을 그대로 반복하지 않습니다.
{/if}
{#if 마무리방식 == "독자 질문"}
- 독자가 자기 상황에 대입해 볼 질문 하나로 끝냅니다. 선택지가 있다면 두 가지 모두 장단점이 있게 씁니다.
{/if}
{#if 다음행동 == "저장 유도"}
- cta는 나중에 다시 꺼내 볼 이유와 함께 저장을 권합니다. 예: "다음에 같은 고민이 생기면 꺼내 보세요"
{/if}
{#if 다음행동 == "본문 기사 읽기"}
- cta는 본문 기사에서 더 알 수 있는 구체적인 내용 하나를 밝히고 안내합니다. 결론을 감춘 채 클릭만 요구하는 문구는 쓰지 않습니다.
{/if}
{#if 다음행동 == "댓글로 의견 남기기"}
- cta는 답하기 쉬운 선택형 질문으로 댓글을 청합니다.
{/if}
- 다음 행동은 하나만 둡니다. 여러 서비스나 링크를 동시에 권하지 않습니다.
- 마지막 카드 외의 카드에는 cta를 쓰지 않습니다.

톤:
- 친근한 존대어(해요체)로 씁니다. 반말과 평어 종결을 쓰지 않습니다.
- 짧은 문장, 구체적인 숫자와 사물, 일상적인 단어를 씁니다. 과장된 감탄사와 느낌표 남발을 피합니다.
- 가르치는 말투 대신 독자와 함께 확인하는 말투를 씁니다.

사실 기준:
- 수치, 연구, 사례는 원천 자료에 있는 것만 쓰고 sourceNote에 출처를 적습니다. 원천 자료에 없는 수치는 만들지 않습니다.
- 투자, 금융, 건강, 법률 주제는 특정 행동을 직접 권유하지 않고, 마지막 카드 body에 "정보 제공 목적이며 개인 조언이 아니에요"를 넣습니다.
- 실존 인물이나 기업을 비난하거나 단정하는 표현을 쓰지 않습니다.

품질기준:
- 출력이 유효한 JSON이고 cards 수가 선택한 카드 수와 같은가
- 첫 카드 role이 cover, 마지막 카드 role이 closing, 나머지가 body인가
- 표지가 정의형·안내형 문장이 아닌가
- 본문 카드마다 새 정보가 하나씩 있고 중복이 없는가
- 반전 카드가 있고, 그 단서가 앞 카드에 미리 심어져 있는가
- headline 25자, body 80자 제한을 지켰는가
- cta가 마지막 카드에만 하나 있는가
- 해시태그가 본문이 아니라 hashtags 배열에만 있는가
- 원천 자료에 없는 수치를 만들지 않았고 sourceNote가 채워졌는가

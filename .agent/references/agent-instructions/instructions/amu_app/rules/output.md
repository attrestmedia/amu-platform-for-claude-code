# Output & Collaboration Rules

- 모든 답변/설명은 한국어로 작성
- 코드 변경은 **항상 patch(diff)로만** 제시 (전체 파일 재출력 금지)
- 변경 파일 수는 최소화 (요청 범위 밖 리팩토링 금지)
- 스코프 우선순위: `wordpress/` (특히 `wordpress/wp-content/themes/amu24/`)
- `node-app/`는 기본적으로 작업/탐색 대상에서 제외 (사용자가 명시한 경우만 예외)
- 불확실하면 “추정”으로 표시하고, 확인을 위해 어떤 파일/경로를 봐야 하는지 제시

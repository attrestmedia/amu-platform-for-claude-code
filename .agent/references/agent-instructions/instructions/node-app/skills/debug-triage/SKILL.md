# 디버그 트리아지

1. **관찰된 증상을 재진술**
2. 원인 가능 계층 식별: UI / Next 렌더링 / API / DB / 인프라 등
3. 검색을 통해 **진입점(entry point)을 특정**
4. **1~2개의 가설**을 세우고 각 가설을 **반증하는 방법**을 제시
5. **최소 수정안을 구현**하고 **검증 단계를 설명**
6. **최소 패치만 출력**

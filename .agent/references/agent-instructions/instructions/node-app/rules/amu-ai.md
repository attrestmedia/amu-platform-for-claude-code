# AMU AI (providers / billing / safety)

- 프로바이더별 호출 차이를 공통 레이어에서 흡수하는 기존 구조 유지 필수
- 비용(코인/토큰) 관련 변경은 반드시 영향 범위를 요약할 것
- 권한/안전 정책은 서버 권위 주입 우선

## Gen Studio 프롬프트 템플릿 규칙

- 이미지/콘텐츠 프롬프트 템플릿은 UI 입력 필드와 최종 생성 프롬프트를 동시에 만드는 정책 자산으로 취급
- 조건 분기는 최종 프롬프트에 포함할 문장을 고르는 용도로 사용. 조건 설명 자체를 모델에 전달하지 않음
- 템플릿 저장/수정 시 문법 오류, 닫히지 않은 조건 블록, 존재하지 않는 필드 참조, 빈 최종 프롬프트 등 필수 템플릿 구성 요소의 누락 차단

### 선택형 옵션 토큰 계약

- 선택형 옵션은 `;` 구분자로 `라벨; 설명; 프롬프트`까지 분절 가능. 분절 해석은 `parsePromptOptionToken()`(`src/utils/lab/promptTemplateUtils.ts`) 단일 구현을 사용하고 UI/렌더러에서 각각 재구현하지 않음
- 구분자가 없는 레거시 옵션은 기존 `normalizeLabel()` 치환 규칙을 그대로 유지 — 신규 문법 도입이 기존 템플릿 결과를 바꾸지 않아야 함
- 확장 토큰의 프롬프트 분절은 **원문 그대로** 치환. 대소문자·하이픈·따옴표가 의미를 갖는 영어 지시문은 확장 토큰으로만 작성
- 조건 분기(`{#if}`)와 옵션 해석(`resolvePromptSelectOption`)은 **옵션 원문과 라벨 양쪽**으로 매칭. 긴 옵션 값을 조건문이나 외부 호출 인자에 그대로 적지 않음
- 옵션 수가 임계값(기본 12) 이상인 필드는 `SelectGroupCard`가 검색형 셀렉트박스 시트로 자동 전환. 호출부에서 개별 UI를 새로 만들지 않고 `selectDisplay`/`selectSearchThreshold`로 제어
- 옵션 수백 개 규모의 템플릿은 관리자 UI 직접 편집 대신 `genstudio` MCP `upsert_*_prompt_template`로 등록·갱신

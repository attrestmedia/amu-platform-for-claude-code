# AMU Labs의 미션

## 목표

1. **통합 디자인 시스템 구축**: AMU 생태계 전체에서 일관된 UI/UX를 제공하는 공통 컴포넌트 라이브러리 개발
2. **프로토타이핑 허브**: 새로운 UI/UX 아이디어를 빠르게 구현하고 검증하는 실험 환경 제공
3. **멀티 프레임워크 지원**: React/Vue 등 다양한 프레임워크에서 동일한 디자인 시스템을 사용할 수 있도록 추상화
4. **디자인-개발 동기화**: Figma 디자인과 코드 컴포넌트 간 간극을 최소화

## 핵심 원칙

- **아토믹 디자인**: Atom → Molecule → Organism 단계별 조합 가능한 컴포넌트 설계
- **토큰 우선**: 하드코딩 대신 디자인 토큰을 통한 테마/스타일 관리
- **접근성 내장**: 시맨틱 마크업, ARIA, 키보드 내비게이션을 기본값으로
- **성능 의식**: 번들 사이즈, tree-shaking, 렌더링 효율을 항상 고려
- **시각적 검증**: 모든 컴포넌트는 Storybook Story와 함께 개발

## AMU 생태계와의 관계

- AMU Labs에서 검증된 컴포넌트는 `amu_app/node-app`(메인 서비스)에 통합
- 디자인 토큰은 AMU 전체 서비스의 light/dark 테마, 반응형 브레이크포인트에 활용
- 미니앱/미니게임의 공통 UI 요소도 이 라이브러리에서 관리

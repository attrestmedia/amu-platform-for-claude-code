## 1. 결론 (포지셔닝)

AMU Magazine은 **다주제 콘텐츠 허브로 유지**한다. 주제를 좁히지 않되, 내부 구조를 선명하게 만들어 "다양한 주제가 섞인 사이트"가 아니라 **넓은 주제로 유입을 만들고 내부에서 AMU 제품 축으로 회유시키는 콘텐츠 허브**로 운영한다.

채널별 역할 분담:

```text
AMU Magazine    = 넓은 주제의 콘텐츠 허브 + 검색 유입 실험장 + 브랜드 신뢰 자산
신규 네이버 블로그 = AI 실전 활용 전문 채널 + Gen Studio/Tutors 전환 입구
Threads / LinkedIn / Instagram = 스토리, 인사이트, 실험 과정, 재가공 채널
```

- 매거진은 직접 판매 채널이 아니라 **오가닉 유입과 신뢰를 쌓는 넓은 입구**다. 기존 TASK 기준도 매거진 재방문/구독 + Gen Studio 간접 전환이며, 본문은 소스 기반 유지 + 내부 링크 클러스터로 체류·회유 동선을 만든다.
- 매거진을 네이버 블로그처럼 좁히는 것은 손해다. 검색 유입이 올라오기 시작했다는 것은 특정 글/카테고리가 이미 반응하고 있다는 뜻이다.

## 2. 금지 사항 (지금 하면 안 되는 것)

- **원인 확인 전 방향 전환 금지**: "AMU는 AI 플랫폼이니까 매거진도 AI 글만 쓴다"는 성급한 결정이다. 유입 상승의 원인(경제/투자/AI 템플릿/자기계발 중 무엇인지)을 확인하기 전에 방향을 틀면 올라오던 검색 신호를 끊을 수 있다.
- **카테고리 갈아엎기 금지**: 방문자 상승기에는 이기는 주제를 확인하고 체계화하는 것이 우선이다.
- **발행 후 방치 금지**: 콘텐츠는 작성 → 예약 → 발행 → 초기 성과 → 7일 성과 → 30일 성과 → 리라이팅 → 재배포 → 폐기의 수명 주기로 관리한다 (`marketing_develop_plan.md` 참조).

## 3. 주제별 역할 구조 ("매거진은 넓게, 운영은 좁게")

핵심은 주제 축소가 아니라 **주제별 역할 분리**다. 모든 주제는 AMU와 연결되는 해석 축을 가져야 한다.

| 구분 | 역할 | 예시 주제 | 전환 방식 |
| --------------- | --------- | ------------------------------------- | --------------- |
| Core | 제품과 직접 연결 | AI 이미지, 프롬프트, Gen Studio 템플릿, 콘텐츠 자동화 | Gen Studio 체험 |
| Adjacent | 타깃 독자 확장 | 비즈니스, 마케팅, 생산성, 자기계발 | 뉴스레터/재방문/서비스 인지 |
| Authority | 신뢰 확보 | 경제, 투자, 산업 변화, AI 인프라 | 브랜드 신뢰 |
| Commerce Bridge | 제품 활용 연결 | 패션, 상세페이지, 쇼핑몰, 상품사진 | Gen Studio 이미지 |
| Build in Public | AMU 성장 서사 | 블로그 재출발, 마케팅 자동화 실험, 개발 과정 | 팔로우/기대감 |

해석 축 예시:

- 투자 글: 단순 "종목 분석"은 AMU와 멀다 → "AI 데이터센터 전력 수요와 콘텐츠 산업의 변화"로 쓰면 브랜드 신뢰(Authority)에 기여
- 패션 글: 단순 트렌드 소개는 멀다 → "의류 쇼핑몰 상세페이지에서 AI 모델컷을 활용하는 법"으로 쓰면 Gen Studio(Commerce Bridge)와 연결

## 4. 발행 비중 가이드

| 영역 | 발행 비중 | 이유 |
| ------------------ | -----: | ----------------- |
| AI·Gen Studio·프롬프트 | 35~40% | 제품 전환의 핵심 |
| 비즈니스·마케팅·생산성 | 25~30% | 타깃 독자와 잘 맞음 |
| 경제·투자·산업 변화 | 15~20% | 검색 유입과 신뢰 확보 |
| 패션·커머스·라이프스타일 | 10~15% | 쇼핑몰/이미지 생성과 연결 가능 |
| AMU 빌드 인 퍼블릭 | 5~10% | 브랜드 서사와 팬 확보 |

- 이 비중은 고정값이 아니다. **상위 유입 글 분석 결과에 따라 조정**한다.
- 점수/평가는 예쁜 평가표로 끝내지 않고, 실제 성과와 비교해 다음 콘텐츠 생성과 채널 선택 정책에 반영한다 (`KPI → 캠페인 → 채널별 콘텐츠 → 발행 → 성과 → 재작성` 폐루프).

## 5. 트래픽 신호 해석 기준 (일 방문 500명 단계)

일 방문 10명 → 500명 상승은 "실험할 데이터가 생겼다"는 신호이며, 축배 단계가 아니다. 방향 결정 전 확인 항목:

```text
1. 유입을 만든 상위 20개 글
2. 유입 검색어
3. 카테고리별 방문 비중
4. 체류시간과 이탈률
5. Gen Studio / app.allmyuniverse.com 클릭 여부
```

분석 결과에 따른 분기:

| 상위 유입 주제 | 대응 |
| ---- | ---- |
| AI·프롬프트·템플릿 글 | 매거진을 AI 실전 활용 허브 쪽으로 더 강화 |
| 경제·투자 글 | 카테고리 유지 + 글 하단에 "AI로 리서치/요약/콘텐츠화" 브릿지 삽입 |
| 패션 글 | 의류 쇼핑몰·모델컷·룩북·상세페이지 이미지로 연결 |

## 6. 매거진 vs 신규 네이버 블로그 운영 차이

두 채널을 같은 전략으로 운영하면 실패를 반복한다.

- **신규 네이버 블로그**: 좁게. 정체성을 "소상공인·1인 셀러·직장인을 위한 AI 실전 활용 블로그"로 잠그고 카테고리 5개(AI 이미지 만들기 / AI 글쓰기·콘텐츠 / 1인 사업 마케팅 / AI 첫걸음 / 만들면서 배운 것) 고정 (`blog_글감_선별_전략.md` 참조)
- **매거진**: 넓게. 대신 모든 글을 내부 링크로 제품 축에 연결

내부 링크 브릿지 패턴:

```text
경제 글    → AI가 바꾸는 산업 구조 → AI 콘텐츠 생산성 → Gen Studio 콘텐츠 템플릿
패션 글    → 쇼핑몰 상세페이지 → AI 모델컷 → Gen Studio 이미지 템플릿
자기계발 글 → 집중력/생산성 → AI 업무 자동화 → Tutors 또는 Gen Studio 콘텐츠 생성
비즈니스 글 → 1인 사업 마케팅 → SNS 콘텐츠 자동화 → Gen Studio 콘텐츠 템플릿
```

## 7. 실행 체크리스트 (2주 데이터 관찰 기간)

글 방향을 바꾸기 전에 데이터부터 확인한다.

```text
1. 최근 28일 상위 유입 글 30개 추출
2. 글별 카테고리, 검색어, 체류시간, 클릭 경로 확인
3. 각 글을 Core / Adjacent / Authority / Commerce Bridge / Build in Public으로 분류
4. Gen Studio 또는 Tutors로 연결 가능한 글에 CTA 카드 삽입
5. 반응 좋은 카테고리는 허브 글 + 심화 글 2~3개로 클러스터화
```

## 8. 운영 원칙 요약

```text
매거진은 넓게 유지.
네이버 블로그는 좁게 운영.
매거진의 모든 글은 내부 링크로 제품 축에 연결.
유입이 오른 카테고리는 죽이지 말고 클러스터화.
성과 없는 주제는 점진적으로 줄이기.
```

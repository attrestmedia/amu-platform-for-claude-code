# 신규 네이버 블로그 글감 소재 선별 전략

## 관련 문서

- `AMU_매거진_사이트_운영_전략.md`
- `Social_channel_전략.md`

## 1. 결론 (선별 파이프라인)

AMU Magazine MCP를 **매번 실시간 검색해서 바로 생성하는 방식은 메인 전략으로 쓰지 않는다** (보조 도구로만 허용). 기본 구조는 **검색 → 후보 큐 편입 → 점수화 → 선별 생성**이다.

```text
AMU 매거진 전체 글
↓ 정기적으로 후보 수집 (주 1회)
신규 네이버 블로그용 소스 큐 구축 (sources.json)
↓ 클러스터/전환/검색의도/중복위험 점수화
우선순위 높은 글부터 재조합
↓
발행 URL과 성과를 다시 원장에 기록
```

실시간 검색-즉시 생성 방식의 세 가지 문제:

1. 그때그때 잘 검색되는 글만 고르게 되어 클러스터가 쌓이지 않는다.
2. 비슷한 소재를 반복 선택할 수 있어 중복 관리가 약해진다.
3. 매거진의 주제 혼재가 새 블로그로 새어 들어온다 (가장 위험).

## 2. 전제: 매거진은 "지도"가 아니라 "광산"

- 매거진은 제품 템플릿·경제·비즈니스·투자·패션이 섞인 콘텐츠 허브이며, 이 구조는 매거진에는 적합하다. 그러나 새 네이버 블로그가 이 카테고리 구조를 따라가면 실패를 반복한다.
- 기존 블로그 실패 원인: **WP 재게시로 인한 유사문서, 주제 혼재로 인한 C-Rank 미형성, 검색 수요 없는 제목**. 새 블로그 전략의 중심은 "무엇을 쓸까"가 아니라 "무엇을 반복하지 않을까"다.
- 새 블로그는 매거진이라는 원석 창고에서 **AI 실전 활용으로 재가공 가능한 글만 캐내는 채널**이다.

## 3. 카테고리 고정 (5종)

새 블로그 정체성: **소상공인·1인 셀러·직장인을 위한 AI 실전 활용 블로그**

| 우선순위 | 카테고리 | 비중 | 핵심 전환 |
| ---: | ---------- | --: | -------------- |
| 1 | AI 이미지 만들기 | 35% | Gen Studio 이미지 |
| 2 | AI 글쓰기·콘텐츠 | 25% | Gen Studio 콘텐츠 |
| 3 | 1인 사업 마케팅 | 20% | Gen Studio 활용 |
| 4 | AI 첫걸음 | 15% | Tutors/입문 신뢰 |
| 5 | AMU 개발 스토리 | 5% | 브랜딩/구독 |

- 네이버 블로그는 "잡지"가 아니라 **주제 신뢰도 채널**로 키운다.
- 카테고리 신설/변경은 분기 리뷰에서만 허용. 발행 비중은 최근 20개 글 기준으로 관리.

## 4. MCP 활용 원칙: 후보 큐 생성 전용

```text
매일 생성 시 MCP 검색               ❌
주 1회 MCP로 후보 20~50개 수집       ⭕
그중 점수 높은 5~10개만 sources.json 등록 ⭕
생성 시에는 sources.json의 pending 항목만 처리 ⭕
```

- `sources.json` = "AMU 매거진 → 신규 네이버 블로그 재조합 소스 큐" 운영 원장. 카테고리 5종에 부합하면서 Gen Studio/Tutors 전환 장면이 있는 기사를 우선 등록한다.

### MCP 검색 쿼리 제한

자유 검색은 주제 혼재를 다시 불러온다. 검색 쿼리를 카테고리별로 제한한다.

```json
{
  "cluster": "ai-image",
  "queries": ["AI 상품사진", "상세페이지 이미지", "모델컷 생성", "썸네일 만들기", "인스타 카드뉴스 이미지"],
  "exclude": ["투자", "부동산", "패션 트렌드 단독", "경제 전망", "자기계발 에세이"]
}
```

- 원칙: **주제를 가져오는 게 아니라 사용 상황을 가져온다.**
  - 패션 글 → "여성 의류 쇼핑몰 상세페이지용 AI 모델컷 만들기"로 바꿀 수 있으면 후보
  - 경제 글 → "소상공인이 경기 침체기에 마케팅 비용을 줄이기 위해 AI 콘텐츠를 쓰는 법"으로 바꿀 수 있으면 후보

## 5. 글감 선별 점수표 (100점)

| 항목 | 배점 | 판단 기준 |
| ----------- | -: | ------------------------------------- |
| 클러스터 적합도 | 25 | 5개 카테고리 중 하나에 명확히 들어가는가 |
| 검색 의도 | 20 | 네이버에서 실제 검색할 만한 문제인가 |
| 전환 연결성 | 20 | Gen Studio/Tutors 사용 장면으로 자연스럽게 이어지는가 |
| 재조합 가능성 | 15 | 원문을 복붙하지 않고 새 글로 바꿀 수 있는가 |
| 롱테일 키워드 가능성 | 10 | 제목 앞쪽에 넣을 구체 키워드가 있는가 |
| 내부 링크 기여도 | 10 | 기존/예정 클러스터 글과 연결되는가 |

판정 기준:

```text
85점 이상: 즉시 후보 등록
70~84점: 앵글 수정 후 보류 후보
69점 이하: 새 블로그용 제외
```

- **"좋은 매거진 글"과 "좋은 네이버 블로그 글감"은 다르다.** 투자/부동산, 자기계발 에세이 원문 톤, 보도자료형 서비스 소식은 발행 금지 주제이며, AI 활용 관점으로 완전히 재프레이밍 가능한 경우에만 후보가 된다 (예: "AI로 투자 리포트 요약하는 법").

## 6. 글감 유형 우선순위 (R 등급 — 정본은 `MARKETING-STRATEGY.md`의 "R Routing" 절)

**재방문과 관계 행동에 기여하는 글감(R0)을 우선한다.** 아래 R1 이하는 기사 맥락이 성립할 때만 확장 CTA를 붙인다.

### R1: 창작 확장형 — 기사에 나온 프롬프트를 독자가 자기 버전으로 바꿔 보는 소재

```text
AI 상품사진 만들기 / AI 모델컷 생성 방법 / 스마트스토어 상세페이지 이미지 만들기
블로그 썸네일 AI로 만드는 법 / 인스타 카드뉴스 문구 생성하기
```

### P1: 문제 해결형 — 1인 셀러·소상공인·크리에이터의 실제 문제

```text
상세페이지 문구가 안 써질 때 / 블로그 글감이 없을 때
인스타그램 콘텐츠를 매일 못 올릴 때 / 상품사진 촬영비가 부담될 때
```

사람은 도구 이름보다 자기 문제를 먼저 검색하므로 네이버 검색과 잘 맞는다.

### P2: AI 입문형 — 신뢰 축적 (전환은 느림)

```text
AI 이미지 생성 처음 시작하는 법 / 프롬프트가 뭔가요
챗GPT와 이미지 생성 AI 차이 / AI로 콘텐츠 만들 때 저작권 주의점
```

### P3: 빌드 인 퍼블릭 — 네이버에서는 5%만

```text
검색 막힌 블로그를 버리고 새로 시작한 이유
AI 마케팅 도구로 글감을 고르는 과정
네이버 블로그 글 하나가 만들어지는 흐름
```

- 실제 작업만 에피소드로 쓴다. 발행 리듬: Threads 주 2~3회, 신규 네이버 블로그 build-log는 격주 1회 제한. 이 유형은 Threads/LinkedIn에서 더 강하게 쓴다.

## 7. 운영 흐름 (표준 사이클)

```text
1. 주 1회 AMU Magazine MCP로 후보 검색
2. 후보마다 5개 카테고리 매핑
3. 후보 점수 산정
4. 상위 후보만 sources.json 등록
5. 생성 시 pending 1건 선택
6. 원문 조회 후 네이버 전용 재조합
7. channelFit 85점 이상만 발행 후보
8. 수동 발행 후 publishedUrl 기록
9. 다음 글부터 내부 링크 대상으로 사용
```

재조합 규칙: 네이버 글은 매거진 글의 복제가 아니다. **핵심 인사이트 하나를 추출해 네이버 검색 독자의 문제 상황으로 재정의하고, 해요체 실용 가이드로 새로 작성**한다. 제목·문단 구조·원문 문장 재사용 금지.

## 8. 최종 원칙

```text
AMU Magazine MCP는 사용한다. 단, 즉흥 검색-즉시 생성은 하지 않는다.

MCP            = 후보 발굴용
sources.json    = 운영 원장
cluster-map.json = 내부 링크 지도
channelFit      = 발행 게이트
성과 데이터      = 다음 후보 선정의 근거
```

> 매거진에서 글감을 찾되, 매거진처럼 운영하지 않는다.
> 새 네이버 블로그는 AMU Magazine의 복사본이 아니라, **Gen Studio와 Tutors로 이어지는 검색형 입구**다.

# AMU 콘텐츠 생성 및 마케팅 전략 가이드

## 1. 지금 팔아야 할 것은 무엇인가

- AMU 콘텐츠가 당장 팔아야 하는 것은 "AI 서비스 플랫폼 전체"가 아닌, **소규모 비즈니스 운영자와 1인 크리에이터가 바로 쓸 수 있는 이미지/콘텐츠 제작 능력**
- 이 능력을 가장 먼저 상품화할 수 있는 서비스는 이미 출시된 `Gen Studio`입니다.

### 1.1 1순위 전환 상품의 정의

> Gen Studio: 마케팅, 커머스, 브랜드 운영에 필요한 이미지와 콘텐츠를 템플릿 기반으로 빠르게 만드는 AI 제작 스튜디오
> AMU Magazine(`allmyuniverse.com`): 신뢰와 검색 유입을 만드는 콘텐츠 허브로 독자가 "좋은 정보"를 얻는 느낌으로 들어오게 만들고, 글의 실전 예시와 CTA에서 자연스럽게 AMU의 서비스 체험으로 연결

### 1.2 콘텐츠 마케팅 서비스 정의

- `Tutors`, `store`, `play`는 각각 다른 구매 동기를 가지며, **개별 콘텐츠는 한 가지 전환 목표만 가져야 함**
- `Gen Studio`(출시): **지금 전환시킬 핵심 상품**. 이미지 생성, 콘텐츠 생성, 템플릿 활용법, 상품 사진, SNS 소재, 상세페이지 카피.
- `store`(준비 중): Gen Studio의 실전 사용처. 스마트스토어 상품 정보, 상세 HTML, 상품 이미지, 쇼룸 운영을 연결하는 커머스 실행 사례.
- `Tutors`(준비 중): AI 활용을 배우고 개인화하는 학습/코칭 상품. 튜터 만들기, 학습 루틴, 업무 지식 도우미.
- `play`(준비 중): 장기 브랜드와 세계관 자산. 캐릭터, 유니버스, 개발 스토리, 게임형 경험.

## 2. 전략적 프레임: 콘텐츠는 기능 소개가 아니라 사용 장면을 팔아야 한다

AMU 서비스의 장점은 **단일 기능이 아닌 연결 구조**에 있지만, 초기 콘텐츠에서는 연결 구조보다 "지금 내 문제를 해결한다"는 사용 장면으로 고객 우선 확보

### 2.1 핵심 판매 문장

마케팅 콘텐츠는 아래 문장을 기준으로 주제를 좁힐 것.

> AMU는 AI로 이미지, 글, 학습, 상점, 플레이 경험을 만드는 플랫폼이지만, 지금 콘텐츠의 1차 목표는 Gen Studio를 통해 독자가 당장 하나의 이미지나 콘텐츠를 만들어보게 하는 것.

### 2.2 우선 타깃

초기에는 넓은 "AI 관심층" 보다 다음 순서로 주제를 좁힌 정밀한 타깃층을 설정할 것.

1. 1인 셀러, 스마트스토어 운영자, 소규모 브랜드 운영자
2. 마케터, 콘텐츠 담당자, SNS 운영자
3. 프리랜서, 1인 사업자, 지식 콘텐츠 크리에이터
4. AI 활용을 배우려는 직장인과 학생
5. 게임/세계관 팬층

- 1차 고객은 **독자**다. 위 타깃 구분은 독자 세그먼트이며, 서비스 사용자 구분이 아니다(`.agent/amu-platform-guide/BUSINESS-CHARTER.md` §5).
- `play`는 출시 준비 단계이므로 체험 CTA를 붙이지 않는다(R3). `Tutors`는 **베타 출시(운영 중)**이므로 기사 맥락에서 질문·학습이 성립할 때 확장 CTA를 허용한다(R1).
- **어떤 서비스도 1차 전환축이 아니다**(ADR #1 superseded). 1차 목표는 재방문과 관계 행동이며, 확장 경험은 기사 맥락에서만 제안한다.

### 2.3 콘텐츠의 역할 분리

- 매거진 원문: 검색 유입과 신뢰 형성. 문제를 자세히 설명하고 실전 활용 방법 제공.
- 네이버 블로그: 검색 질문에 답하는 실용 가이드. "방법", "예시", "체크리스트" 중심.
- 링크드인: 운영/비즈니스 인사이트. "작게 시작하는 AI 워크플로우" 중심.
- 스레드: 짧은 팁과 프롬프트 조각. 저장하고 따라 할 수 있는 압축 정보.
- 인스타그램: Gen Studio 결과 이미지, Before/After, 카드뉴스가 있을 때만 선택적으로 사용.

## 3. 투트랙 콘텐츠 전략

### Track A. 창작·제작 실전 — 기사 맥락의 확장 경험(R1)

- 가장 먼저 실행할 트랙.
- 목표: 독자가 글을 읽고 **그 기사에 나온 프롬프트를 자기 버전으로** 바꿔 보게 하는 것. 범용 진입(`/gen-studio` 단독 링크)이 아니라 **기사 맥락 파라미터를 동반한 딥링크**를 쓴다.
- 핵심 주제는 다음 순서로 배치.

1. AI 상품 사진/상세페이지 이미지 만들기
2. 스마트스토어 썸네일과 상세페이지 이미지 개선
3. SNS 카드뉴스/배너/광고 이미지 만들기
4. 브랜드 무드보드와 룩북 이미지 만들기
5. 블로그 글, 상품 설명, SNS 카피를 템플릿으로 만들기
6. 프롬프트 변수를 바꿔 여러 버전을 만드는 법
7. 좋은 AI 결과물을 고르는 체크리스트

- 권장 글 구조.

1. 독자의 현실 문제: 사진 촬영비, 디자인 시간, 매번 달라지는 결과물.
2. 원리 설명: 템플릿, 변수, 레퍼런스, 모델 선택이 결과를 안정화하는 이유.
3. 실전 예시: 업종별 프롬프트/이미지/카피 예시.
4. 체크리스트: 바로 따라 할 수 있는 입력 항목.
5. CTA: Gen Studio의 특정 템플릿 또는 템플릿 목록으로 1회 연결.

- CTA는 광고 문구가 아닌 행동 안내를 통해 행동을 유도.

1. 좋은 CTA: "같은 구조의 이미지 프롬프트를 Gen Studio 템플릿에서 바로 바꿔 볼 수 있습니다."
2. 피해야 할 CTA: "최고의 AI 이미지 생성 플랫폼 Gen Studio를 지금 이용하세요."

### Track B. 개발/출시 스토리 활용: 서비스에 대한 기대감과 신뢰 축적

- Git 커밋과 개발 변경 사항을 소재로 사용. 
- 목표: "열심히 만들고 있다"가 아닌 **사용자가 겪을 문제를 어떻게 줄이고 있는지**를 보여주는 것.

최근 커밋 기반 스토리 예시.

1. Gen Studio 템플릿 목록 로딩/인피니트 스크롤 개선: 많은 템플릿을 탐색할 때 기다림과 막힘을 줄인 이야기.
2. Gen Studio 이미지 생성 화면 개선: 이미지 생성의 입력, 미리보기, 결과 확인 흐름을 낮춘 이야기.
3. 마케팅 소셜 draft Gen Studio 이미지 워크플로우: 콘텐츠 제작과 이미지 생성을 한 흐름으로 연결한 이야기.
4. 스마트스토어 안전 HTML 제한형 리치 텍스트 에디터: 상세페이지 편집에서 표현력과 안전성을 함께 확보한 이야기.
5. 스마트스토어 상품 가져오기/전체 동기화 응답 매핑 수정: 외부 상품 데이터를 안정적으로 가져오는 운영 품질 이야기.

글의 핵심은 기술 변경 자체가 아닌 아래의 구조로, 예를 들어 "인피니트 스크롤 개선"은 개발자에게는 UI 성능 작업이지만, 콘텐츠에서는 "템플릿이 많아질수록 고르는 일이 어려워지는 문제를 어떻게 줄였는가"로 번역해야 함.

> 사용자 문제 -> 제품 결정 -> 구현 변화 -> 사용자가 느낄 변화 -> 다음 단계

## 4. 서비스별 콘텐츠 포지셔닝 가이드

### 4.1 Gen Studio

- 상태: 출시 후 고도화 중.
- 판매 포인트: 템플릿 기반 이미지/콘텐츠 생성, 마케팅/커머스/브랜드 활용, 반복 가능한 결과물.
- 핵심 독자: 1인 셀러, 마케터, 소규모 브랜드, 콘텐츠 크리에이터.
- 콘텐츠 톤: 친근하지만 실무적. "오늘 필요한 소재를 만드는 법".
- 우선 CTA: `/gen-studio/templates` 또는 `?mode=image|content&view=detail&templateKey=...`
- 금지: Gen Studio를 만능 디자인 대체재로 과장하지 않기. 결과물 검수와 커스터마이징 필요성을 함께 설명.

추천 시리즈:

- `AI 상품 사진 프롬프트 가이드`
- `스마트스토어 썸네일 개선 체크리스트`
- `상세페이지 이미지 톤 통일법`
- `콘텐츠 프롬프트 템플릿으로 블로그 초안 만들기`
- `SNS 카드뉴스 문구를 프롬프트 변수로 설계하는 법`

### 4.2 Tutors

- 상태: 출시 예정 또는 공개 고도화 단계.
- 판매 포인트: 내가 만든 AI 튜터와 학습/대화/코칭을 반복하는 경험.
- 핵심 독자: AI 활용을 배우려는 직장인, 학생, 크리에이터, 소규모 운영자.
- 콘텐츠 톤: 학습 루틴, 질문법, 개인화된 도움의 가치.
- 우선 CTA: 출시 전에는 "출시 예정", "개발 중인 기능", "학습 시나리오"로 자연스럽게 언급.
- 금지: 의료, 법률, 투자 등 고위험 조언을 튜터가 확정적으로 해결한다고 표현하지 않기.

추천 시리즈:

- `AI 튜터에게 질문을 잘하는 법`
- `업무 지식을 튜터로 정리하는 방법`
- `콘텐츠 제작자가 자기만의 피드백 튜터를 만드는 이유`
- `학습 루틴을 챗봇과 함께 설계하는 법`

### 4.3 Store

- 상태: 출시 예정 또는 연동 고도화 단계.
- 판매 포인트: 상품 정보, 이미지, 상세페이지, 쇼룸을 AI 제작 흐름과 연결.
- 핵심 독자: 스마트스토어 운영자, 1인 셀러, 소규모 브랜드.
- 콘텐츠 톤: 운영자의 시간과 반복 작업을 줄이는 실무 가이드.
- 우선 CTA: Gen Studio 이미지/카피 제작으로 연결하고, Store는 "곧 연결될 사용처"로 소개.
- 금지: 외부 플랫폼 정책, 매출 상승, 광고 성과를 근거 없이 단정하지 않기.

추천 시리즈:

- `상품 상세페이지 이미지와 문구를 함께 설계하는 법`
- `스마트스토어 상품 데이터를 AI 콘텐츠로 바꾸는 과정`
- `상점 운영자가 먼저 자동화해야 할 반복 작업`
- `브랜드 쇼룸과 상품 페이지의 역할 차이`

### 4.4 AMU Play

- 상태: 출시 예정.
- 판매 포인트: 유니버스를 선택해 게임형 경험으로 진입하는 브랜드/세계관 플랫폼.
- 핵심 독자: 세계관, 캐릭터, 인터랙티브 경험에 관심 있는 독자.
- 콘텐츠 톤: 제작기, 캐릭터/세계관 설정, 실험 기록.
- 우선 CTA: 직접 판매보다 매거진 체류, 팔로우, 개발 스토리 구독.
- 금지: 커머스/교육/게임을 한 글에서 모두 팔려고 하지 않기.

추천 시리즈:

- `AMU Play 유니버스 제작 노트`
- `캐릭터와 상호작용 경험을 설계하는 법`
- `게임형 서비스에서 세계관 문서가 중요한 이유`

## 5. 콘텐츠 우선순위 가이드

### 5.1 우선순위 등급

> **판정 정본은 `.agent/amu-platform-guide/MARKETING-STRATEGY.md`의 "R Routing" 절 표다.** 아래는 그 요약이며 충돌 시 정본이 우선한다.

- R0: 관계 행동 직결. 시리즈·연재·클러스터 소재, 실행 체크리스트·템플릿이 딸린 소재 → 저장·팔로우·구독 CTA.
- R1: 기사 맥락의 확장 경험 직결. 이미지·콘텐츠 프롬프트, 상품 사진, 썸네일, 카드뉴스(창작) / 어려운 개념·학습·코칭(질문).
- R2: 확장 간접. AI 활용법, 프롬프트 엔지니어링, 콘텐츠 자동화, 생산성, 마케팅 전략 — 맥락이 약하면 관계 CTA로 대체한다.
- R3: 미공개 서비스 브랜딩. 캐릭터, 세계관, 게임, 커머스 운영 철학 — 기대감 CTA만.
- R4: 일반 유입. 자기계발, 투자, 금융, 일반 비즈니스 인사이트.

금융·투자·세무·의료·법률 소재는 **R4 고정이며 확장 CTA를 붙이지 않는다**(자문 오인 방지). "AI로 투자 리서치 노트 만들기"처럼 창작 장면이 명확해도 이 축에서는 관계 CTA만 쓴다.

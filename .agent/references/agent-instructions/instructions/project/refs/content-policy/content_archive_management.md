# Content Archive Management Rules

## 보관 원칙

- 기존 기록은 삭제/재정렬보다 추가를 우선
- 파일 자동 삭제 금지, 정리 시 근거 기록 필수
- 대용량 문서 편집은 최소 범위 패치로만 반영

## 데이터 형식 원칙

- JSON은 UTF-8 유지 및 기존 스키마 유지
- TSV/TXT는 헤더와 구분자(탭/개행) 보존
- 한글 깨짐, 인코딩 깨짐, 줄바꿈 손상 방지

## 검증 체크

- 날짜/요금/정책 데이터는 기준일을 반드시 명시
- 외부 링크는 저장 전 1차 유효성 확인
- 이메일/토큰/비밀번호 등 민감정보는 마스킹하거나 제외

## 콘텐츠 생성/발행 로그(중복 방지)

- 이미 생성/발행한 콘텐츠 추적용 append-only 로그를 둔다: `.agent/content/content-ledger.jsonl` (JSON Lines)
- 보관 원칙 동일 적용: 기존 줄은 수정/삭제 금지, 추가만 한다
- 상세 운영 규칙(생성 전 확인 / 생성 후 기록 / Git 소스 `dedupeKey` 정규화)은 `content_production_workflow.md`의 `콘텐츠 생성/발행 로그(중복 방지)` 섹션을 단일 기준으로 따른다

# Writing Humanizer Rules

## 목적

AI가 생성한 텍스트의 흔적을 제거하고 자연스러운 한국어 문체로 편집한다.
SKILL.md(`{{AGENT_ROOT}}/skills/writing-humanizer/SKILL.md`)의 27개 패턴이 세부 기준이며,
이 파일은 적용 우선순위와 워크플로우 연계 규칙을 정의한다.

---

## 적용 우선순위

1. **신규 기사 초안**: `{{AGENT_ROOT}}/refs/content-policy/magazine_knowledge_article.md` 규칙으로 초안 생성 → 이 규칙으로 최종 편집
2. **마케팅 채널 콘텐츠**: `{{AGENT_ROOT}}/refs/content-policy/marketing_content_pipeline.md` 기준 생성 후 채널 발행 전 적용
3. **기존 콘텐츠 재가공**: 아카이브 문서 편집 시 선택적 적용

## 핵심 금지 패턴 (우선순위 상위)

아래 패턴은 발행 전 반드시 제거한다.

### 대화형 챗봇 흔적

- "좋은 질문이시네요!", "도움이 되셨으면 좋겠습니다!", "알려주세요"
- "여기 ~가 있습니다...", "물론이죠!", "당연하죠!"

### 홍보성·광고성 어휘

- 숨막히는, 획기적인, 활기찬, 심오한, 놀라운, 꼭 방문해야 할
- ~을 자랑합니다, ~의 헌신, ~의 중심부에 자리 잡은

### AI 고빈도 어휘

- 또한, 중요한, 지속적인, 핵심적인, 결정적인, 태피스트리, 지형(추상명사)
- 향상시키다, 촉진하다, 강조하다, 선보이다, 활기찬, 복잡성

### 계사 회피

- "~의 역할을 합니다" → "~입니다"
- "~을 자랑합니다" → 직접 서술
- "~을 제공합니다" → 구체적 동사로 교체

### 과도한 헤징

- "잠재적으로 주장될 수 있을 것입니다" → 단호하게 서술
- "[날짜] 기준으로", "가용한 정보에 기반하여" → 삭제 또는 구체적 출처로 교체

## 문체 규칙

### 구조적 패턴 제거

- **부정 대구 금지**: "단순히 X가 아닙니다. Y입니다" → 직접 서술
- **3의 법칙 남용 금지**: 의미 없는 3개 나열 → 필요한 것만
- **~하며 구문 제거**: 피상적 분석용 "~을 강조하며", "~을 반영하며" → 독립 문장화
- **동의어 순환 금지**: 주인공/주요 인물/중심 캐릭터/영웅 반복 → 하나로 통일

### 서식 규칙

- **굵은 글씨**: 진짜 강조가 필요한 곳만 (기계적 구문 강조 금지)
- **이모지**: 제목·글머리에 이모지 장식 금지
- **줄임표·대시**: 문장 강조용 남용 금지, 필요한 곳만
- **인라인 헤더 목록**: `**항목:** 설명` 형태의 목록 → 산문으로 통합
- **따옴표**: 둥근 따옴표("...") 금지, 직선 따옴표("...") 사용

### 한국어 특유 패턴

- **~적(的) 남용 금지**: "혁신적이고 창의적인 전략적 접근" → "새로운 접근"
- **번역투 제거**: "그것은 그 자체로 도전이 됩니다" → "그것 자체가 도전입니다"
- **과도한 존칭 제거**: "심층적으로 분석해 드리도록 하겠습니다" → "분석하겠습니다"
- **명사화 남용 제거**: "전략적 협상 및 파트너십 구축 방안" → "전략적 협상과 파트너십"

## 개성 주입 기준

AI 패턴 제거만으로는 부족하다. 아래 기준으로 목소리를 추가한다.

- **의견 표명**: 사실 나열 대신 반응 ("솔직히 이걸 어떻게 받아들여야 할지 모르겠다")
- **리듬 변주**: 짧은 문장과 긴 문장을 섞는다
- **복잡한 감정 인정**: "대단하긴 한데 좀 찜찜하기도 하다"
- **구체적 감정**: "우려됩니다" → 구체적 상황으로 묘사
- **1인칭 허용**: 적절한 맥락에서 "나는", "저는" 사용

---

## 출처 처리

- **모호한 출처 금지**: "전문가들은 주장합니다", "업계 보고서에 따르면" → 구체적 출처로 교체
- **언론 이름 나열 금지**: 매체 목록 열거 대신 구체적 인용 내용으로 교체

## 처리 흐름

1. 입력 텍스트 전체 스캔 → `{{AGENT_ROOT}}/skills/writing-humanizer/SKILL.md` 27개 패턴 대조
2. 문제 섹션 재작성 (의미 보존, 어조 유지)
3. 개성 주입 여부 검토
4. 소리 내어 읽을 때 자연스러운지 확인
5. 수정된 텍스트 + 변경 사항 요약 제공 (선택)

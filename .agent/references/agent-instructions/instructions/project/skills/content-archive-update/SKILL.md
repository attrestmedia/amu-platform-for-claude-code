# content-archive-update

## 목적

- 대량 문서/데이터 아카이브를 규칙에 맞게 안정적으로 유지
- 포맷 손상, 인코딩 문제, 구조 붕괴를 방지

## 실행 절차

1. 변경 대상의 스키마/포맷 확인
2. 최소 범위 패치로 수정
3. 인코딩(UTF-8), 구분자, 헤더 보존 여부 확인
4. 날짜/링크/수치 데이터 검증
5. 변경 내역을 파일 경로 중심으로 요약

## 필수 체크리스트

- 기존 레코드 삭제보다 추가 우선
- 자동 삭제 금지
- JSON 필드 일관성 유지(`type`, `source`, `quote`, `exp` 등)
- 민감정보 노출 여부 점검

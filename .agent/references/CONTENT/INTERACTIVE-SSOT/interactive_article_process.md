# 게임 에셋을 활용한 인터렉티브 아티클 생성 프로세스

**주요 컨셉 정리**
* Play와 연결되는 인터렉티브 아티클은 home(`https://allmyuniverse.com/`)에 구현되고, 텍스트 및 이미지/영상을 활용한 모션 인터렉티브 아티클로 tiktok처럼 영상 스타일의 ui로 구현 후 short form 스타일의 ui로 적용
* 게임 진행에 따라 AMU 플랫폼의 콘텐츠 생성 파이프라인을 활용하여 사용자가 각 캐릭터의 스토리에 적합한 이미지/동영상 등을 생성하여 숏폼 영상 처럼 아티클을 생성할 수 있음 - 추후 설계 및 구현 예정
* 비 Play 사용자는 인터렉티브 아티클로 구현된 각 캐릭터의 스토리를 숏폼 드라마 처럼 즐길 수 있음

## 최초 진행 범위(생성된 에셋 또는 스토리 진행에 필요한 캐릭터가 생성되지 않은 경우)

1. 캐릭터 생성(기본 캐릭터 시트 + 챗 화면에서 활용할 수 있는 다양한 표정과 동작을 표현한 액션 시트)
	- 관리자 또는 여러 유니버스의 오너인 사용자는 사용 가능한 유니버스를 선택한 후 해당 유니버스의 컨셉이 셋팅된 캐릭터를 생성하고, 특정 단일 유니버스의 오너인 사용자는 자신이 소유한 유니버스가 기본 선택된 상태에서 해당 유니버스의 컨셉이 셋팅된 캐릭터를 생성 
  - 특정 유니버스 생성 시 또는 특정 유니버스의 편집 화면에서 "해당 유니버스에서 생성 가능한 캐릭터 타입(인간 or 몬스터 or 둘다)"을 설정할 수 있음
	- 특정 유니버스의 오너가 아닌 사용자는 특정 유니버스 내에서 해당 유니버스의 컨셉이 셋팅된 자신만의 캐릭터를 생성할 수 있음
		* 추가 예상 작업: 유니버스 편집 화면의 캐릭터 생성 티입 옵션 추가 및 액션 시트용 이미지 생성 프롬프트 제작
		* 첫 번째 생성 캐릭터의 컨셉은 `패션 인플루언서 및 모델(https://assets.allmyuniverse.com/gen-studio/users/2-da4b9237/1786571106645-gpt-image-2-8e6e1699-3nn0g9.webp) - 헤어 스타일을 숏 커트로 바꿔보는 건 어떨까?`로 하고 스토리구조는 패션 인플루언서 및 모델로 활동하는 캐릭터가 AMU Play에서 다양한 미션과 도전, 학습 등의 게임 시뮬레이션을 통해 성공적인 패션 비즈니스를 완성하고 경영해나가는 구조로 진행하는건 어떨까? 실제 Play의 게임으로도 해당 기본 스토리라인을 기반으로 해당 캐릭터만의 게임 시뮬레이션 세계를 구현하고, 다양한 비즈니스 및 마케팅적 지식은 게임 내 interllgence system을 통해 획득하는 구조는?
2. 생성된 캐릭터 시트와 액션 시트를 기반으로 컨셉에 맞는 기본 맵과 게임 에셋 등을 생성하거나 배치하여 기본적인 게임 시뮬레이션 환경 셋팅 
3. 생성된 캐릭터(주인공 캐릭터)의 메인 스토리라인에 맞는 인터렉티브 아티클 기획 및 설계
4. 구현된 인터렉티브 아티클을 전용 Play 전용 CRUD 시스템에 등록 후 홈 화면 노출
